\# Project Statement



\## Library Management System



\### Problem Statement



Managing books, members, and borrowing activities manually can be time-consuming and may lead to errors in maintaining library records. A computerized system is needed to store and manage library information efficiently.



\### Objective



The objective of this project is to develop a console-based Library Management System using Java. The system allows users to manage books and members, issue and return books, maintain transaction records, search for books, and sort books by title.



\### Main Features



\- Add and manage books

\- Register library members

\- Issue books to members

\- Return books

\- View transaction records

\- Search books using Book ID

\- Sort books alphabetically by title

\- Store data using CSV files

\- Handle errors using custom exceptions



\### Technologies Used



\- Java

\- Object-Oriented Programming

\- Collections

\- File Handling

\- Exception Handling

\- CSV Files



\### Expected Outcome



The system provides a simple and organized way to manage basic library operations through a command-line interface. It reduces manual record keeping and demonstrates the practical use of Java programming concepts.
